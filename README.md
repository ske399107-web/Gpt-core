# GPT Core

A responsive, dark-themed landing page and login UI for GPT Core.

## Pages
- \`index.html\` — marketing homepage with hero, feature cards, workflow preview, and responsive navigation.
- \`login.html\` — sign-in interface with email/password fields and social sign-in placeholders.
- \`styles.css\` — responsive visual system, layouts, and motion.
- \`app.js\` — navigation, password visibility, and client-side form validation.

## Run locally
Open \`index.html\` in a browser, or serve this folder with any static web server.

## Authentication note
The login page is a front-end interface only. Email/password submission and Google/GitHub buttons are intentionally not connected to a real authentication service. Configure a trusted backend or OAuth provider before accepting real user accounts. Never put private API keys or client secrets in browser JavaScript.

## Deploy
This is a static site and can be deployed to GitHub Pages, Vercel, Netlify, or any static hosting provider.
